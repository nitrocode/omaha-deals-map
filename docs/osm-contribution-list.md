Per-venue gaps inferred from the photo scrape (`data/photo_cache.yaml`). Each entry links to the iD editor at the venue's coordinates so you can add the missing tag in two clicks.

**Why this matters:** every OSM tag you add benefits every downstream tool, not just this map. The richer the OSM data for Omaha venues, the more useful the map (and OpenStreetMap broadly) becomes.

Common tags worth filling in:
- `website` - the venue's own URL
- `image` - photo of the venue (URL)
- `phone` - international format, e.g. `+1-402-555-0100`
- `opening_hours` - using the OSM [opening_hours](https://wiki.openstreetmap.org/wiki/Key:opening_hours) syntax
- `cuisine` - one or more of the OSM [cuisine](https://wiki.openstreetmap.org/wiki/Key:cuisine) values
